# up release QA

## Public release contract

- Default workspace contains zero companies and zero positions.
- Default intelligence contains zero opportunities and zero role briefs.
- No personal paths, profile data, private screenshots, JD text, notes, or timeline nodes are included.
- Company presets are optional public assets shown only after the user opens the add-position flow.
- Installed data is stored locally in the operating system application-data directory.

## Required checks

1. Overview renders a clear first-run state.
2. A position can be added without generated data.
3. Timeline nodes can be created, edited, connected, and removed.
4. Codex intelligence JSON is readable by the workbench.
5. Production build and desktop package complete successfully.
6. The public tree passes secret and personal-path scanning.
